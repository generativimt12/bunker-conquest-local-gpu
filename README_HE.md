# BUNKER CONQUEST — גרסת GPU מקומית

מקטע FPS תלת־ממדי בדפדפן, המבוסס על PlayCanvas Engine 2 ו־Vite. המנוע מנסה להשתמש ב־WebGPU, וחוזר ל־WebGL 2 כשזמין.

## הפעלה מקומית

נדרשת התקנה של Node.js 20 ומעלה.

```bash
npm install
npm run dev
```

פתחו את כתובת localhost שמודפסת בטרמינל. שרת הפיתוח רק מגיש קבצים; הרינדור נעשה על ה־GPU המקומי. שימוש ב־localhost חשוב לתמיכת WebGPU בדפדפנים רבים.

## בנייה

```bash
npm run build
npm run preview
```

## מקשים

- WASD — תנועה
- עכבר — מבט וכיוון
- קליק שמאלי — ירי
- R — טעינה
- Q — החלפת נשק
- E — אינטראקציה עם הממסר
- Shift — ריצה
- Space — קפיצה
- מסך מגע — ג׳ויסטיק, גרירת מבט וכפתורי פעולה

## פריסה ב־GitHub Pages

הקובץ `.github/workflows/deploy.yml` בונה את המשחק ומעלה אותו ל־GitHub Pages לאחר push ל־main. אם הפריסה אינה מתחילה, פתחו Settings → Pages ובחרו **GitHub Actions** כמקור הבנייה והפריסה.

## מצב הפרויקט

זהו פרוטוטייפ שניתן להרחיב, לא משחק AAA גמור. החומרים והחלק מהנכסים נוצרים בזמן ריצה; עדיין נדרשים מודלים, אנימציות ונכסים אמנותיים מקצועיים כדי להגיע לאיכות חזותית של הפקות AAA. לא בוצעה עדיין בדיקת GPU חיה בסביבה זו, ולכן יש להתייחס ל־build הירוק ב־Actions כבדיקת קומפילציה ולא כהוכחה לבדיקת משחק מלאה בכל מכשיר.
